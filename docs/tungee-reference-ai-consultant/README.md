# 探迹参考研究与云帐房 AI 顾问重构

> 目录用途：沉淀探迹/Tungee 在 B2B 营销获客、AI Sales Agent、企业数据应用方面的调研资料，并作为后续重新思考“云帐房 AI 顾问”产品方向的参考。

## 文件说明

1. `TUNGEE_MARKETING_ACQUISITION_RESEARCH.md`
   - 探迹近期产品体系、营销获客能力、公开披露数据、实现机制整理。

2. `TUNGEE_PUBLIC_EFFECT_VALIDATION.md`
   - 对探迹效果数据的公开验证补充。
   - 区分官方口径、第三方旁证、同类商业模式风险。

3. `YUNZHANGFANG_AI_CONSULTANT_RETHINKING.md`
   - 基于探迹方法，对云帐房 AI 顾问的初步重构思考。
   - 用于下一步展开产品定位、能力地图、数据闭环和落地路径。

## 当前关键判断

探迹值得参考的不是某个单点功能，而是其完整方法：

> 行业数据底座 + 客户画像/意向识别 + AI Agent 推荐动作 + 多渠道触达 + CRM/经营数据闭环。

云帐房 AI 顾问后续可以借鉴这个思路，但不能简单照搬“销售获客工具”。更适合的方向是：

> 基于财税行业经营数据、客户画像、风险信号和服务流程，构建面向代账公司老板、销售、客服、会计主管的 AI 经营顾问与增长助手。
