## 当前校准后的关键判断

内部会议后的判断是：

> 云帐房 AI 顾问 1.0 不应优先定位为“老板经营副驾”或“AI 合规专家”，而应优先定位为面向代账公司顾问/流程会计岗位的“AI 服务协同与流程自动化助手”。

第一阶段重点不是全自动替代顾问与企业老板对话，而是先把顾问每天在客户群里的重复工作自动化：

- 自动/预约发送催票、催税、工资确认、社保确认、资料收集提醒；
- 识别客户回复、附件、图片、表格、语音和关键词；
- 判断资料是否有效、是否收齐、是否需要顾问处理；
- 自动生成待办或更新流程状态；
- 支持顾问快速查询发票、账税、财报、个税、社保、银行和申报数据；
- 给顾问推荐回复话术，由顾问确认后一键发送；
- 将确认、采集、催办、回复、异常处理沉淀到工作台。

探迹、YQY、营销类 AI 产品仍作为外部参考，但不应覆盖内部会议形成的第一阶段产品主线。
