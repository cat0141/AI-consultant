# 客户洞察增长平台字段字典设计

> 更新时间：2026-06-09  
> 适用范围：客户洞察增长线、商机洞察、增长拓客、产品机会评分、洞察模板规则引擎。  
> 文档定位：用于指导字段字典、标签规则、模板规则、关键词词库和权限规则的设计。

## 1. 设计目标

字段字典不能只做成“字段清单”，而要做成一套统一的数据资产配置表，能够同时服务：

1. **前端筛选**：字段能不能作为规则条件；
2. **标签生成**：字段能不能生成客户标签；
3. **商机评分**：字段能不能参与产品机会评分；
4. **结果解释**：客户为什么被推荐，系统能不能说清楚依据；
5. **数据导出**：字段能不能出现在商机名单和导出文件中；
6. **权限合规**：不同角色能不能看、看多少、是否需要脱敏。

字段字典是客户洞察增长平台的底层配置。后续的规则引擎、标签体系、商机模板、AI解释和导出字段都应基于字段字典工作。

## 2. 字段字典总体结构

建议字段字典至少包含以下信息：

| 字段组 | 字段 | 含义 |
|---|---|---|
| 基础信息 | 字段中文名、字段英文名、字段ID | 统一产品、研发、运营命名 |
| 数据来源 | 来源系统、来源表、来源字段、更新频率 | 说明字段从哪里来 |
| 业务口径 | 字段定义、统计周期、计算逻辑 | 说明字段怎么算 |
| 数据类型 | 文本、数值、金额、日期、枚举、布尔、列表 | 决定前端筛选方式 |
| 使用方式 | 可筛选、可导出、可展示、可评分、可打标签 | 决定产品里怎么用 |
| 权限合规 | 敏感级别、脱敏规则、可见角色 | 防止数据越权 |
| 质量控制 | 是否必填、空值处理、异常值规则 | 保证规则稳定 |
| 运营配置 | 所属商机场景、推荐模板、优先级 | 让运营能维护 |
| AI解释 | 字段解释话术、命中解释模板 | 让AI能生成可读解释 |

## 3. 推荐字段字典表头

| 字段 | 说明 |

| 字段中文名 | 例如“年营业收入” |
| 字段英文名 | 可选，用于研发或接口 |
| 字段分组 | 企业基础、工商、票据、财务、税务、服务、沟通、产品使用、商机结果 |
| 字段说明 | 业务解释 |
| 数据来源系统 | 财云、天工、云微、企微、工商接口、发票系统、报表系统等 |
| 来源表/接口 | 具体表名或接口名 |
| 来源字段 | 原始字段名 |
| 数据类型 | 文本、数值、金额、日期、枚举、布尔、关键词列表 |
| 单位 | 元、万元、次、人、户、天、月等 |
| 统计周期 | 当月、当季、近12个月、自然年、累计 |
| 更新频率 | 实时、每日、每月、申报后、手动更新 |
| 计算口径 | 字段如何计算 |
| 枚举值 | 如纳税信用等级：A/B/M/C/D |
| 是否可筛选 | 是/否 |
| 支持操作符 | 等于、不等于、包含、大于、小于、区间、为空、不为空、任一命中 |
| 是否可导出 | 是/否 |
| 是否前端展示 | 是/否 |
| 是否参与评分 | 是/否 |
| 是否可打标签 | 是/否 |
| 适用模板 | 可涨价客户、高新申报、广告营销、合规体检等 |
| 标签生成规则 | 命中后生成什么标签 |
| 命中解释模板 | 用于解释为什么命中 |
| 敏感级别 | 公开、内部、敏感、高敏 |
| 脱敏规则 | 税号脱敏、手机号脱敏、金额区间化等 |
| 可见角色 | 老板、运营、销售、顾问、管理员 |
| 空值处理 | 忽略、按0处理、标记未知、禁止参与规则 |
| 异常值处理 | 负数、极大值、跨期异常如何处理 |
| 字段负责人 | 产品/数据/研发负责人 |
| 状态 | 待确认、可用、口径有争议、暂不可用、废弃 |
| 备注 | 其他说明 |

## 4. 字段分组设计

第一版建议按 9 组管理字段。

### 4.1 企业基础字段

用于识别客户和做基础筛选。

| 字段ID | 字段中文名 | 类型 | 主要用途 |
|---|---|---|---|
| `enterprise_name` | 企业名称 | 文本 | 展示、导出、搜索 |
| `tax_no` | 税号 | 文本 | 唯一识别、数据关联 |
| `registered_address` | 注册地址 | 文本 | 地域筛选 |
| `industry` | 行业 | 枚举/文本 | 行业模板、商机判断 |
| `business_scope` | 营业范围 | 文本 | 高新、资质、工商类商机 |
| `establish_date` | 成立日期 | 日期 | 注册年限、资质判断 |
| `legal_person` | 法人 | 文本 | 工商变更、关系识别 |
| `enterprise_status` | 企业状态 | 枚举 | 排除注销、异常、流失 |

### 4.2 经营规模字段

用于客户价值分层、经营能力判断和商机优先级排序。

| 字段ID | 字段中文名 | 类型 | 主要用途 |
|---|---|---|---|
| `annual_revenue` | 年营业收入 | 金额 | 高价值客户、分层 |
| `monthly_avg_invoice_count` | 月均发票量 | 数值 | 活跃度、工作量 |
| `social_security_count` | 社保人数 | 数值 | 用工服务、人资服务 |
| `bank_account_count` | 银行账户数量 | 数值 | 资金复杂度 |
| `related_company_count` | 关联公司数量 | 数值 | 集团客户、转介绍 |
| `asset_liability_ratio` | 资产负债率 | 百分比 | 融资、风险判断 |

### 4.3 发票字段

用于商机识别，尤其广告营销、开票风险、行业行为判断。

| 字段ID | 字段中文名 | 类型 | 主要用途 |
|---|---|---|---|
| `invoice_item_name` | 发票项目名称 | 文本/关键词 | 广告、技术服务等关键词识别 |
| `invoice_amount` | 发票金额 | 金额 | 投入规模、商机价值 |
| `invoice_date` | 发票日期 | 日期 | 商机新鲜度 |
| `sales_invoice_amount_12m` | 近12个月销项发票金额 | 金额 | 经营规模、升规风险 |
| `purchase_invoice_amount_12m` | 近12个月进项发票金额 | 金额 | 采购结构 |
| `invoice_count_12m` | 近12个月发票数量 | 数值 | 活跃度、工作量 |
| `matched_invoice_keyword` | 发票命中关键词 | 关键词列表 | 命中解释 |

广告/数字营销场景建议沉淀以下衍生字段：

| 字段ID | 字段中文名 | 说明 |
|---|---|---|
| `has_marketing_invoice_keyword` | 是否命中营销类发票关键词 | 命中网络投放、广告投放、数字营销、SEO、SEM等 |
| `marketing_invoice_keyword_list` | 命中营销关键词列表 | 记录具体命中词 |
| `marketing_invoice_amount_12m` | 近12个月营销类发票金额 | 判断投入规模 |
| `marketing_invoice_count_12m` | 近12个月营销类发票数量 | 判断频次 |
| `latest_marketing_invoice_date` | 最近营销类发票日期 | 判断商机新鲜度 |

### 4.4 财务字段

用于高新、合规、融资、涨价判断。

| 字段ID | 字段中文名 | 类型 | 主要用途 |
|---|---|---|---|
| `profit_total_current_year` | 当年利润总额 | 金额 | 高新、融资、经营判断 |
| `rd_expense_current_year` | 当年研发费用 | 金额 | 高新申报 |
| `gross_margin_rate` | 毛利率 | 百分比 | 合规风险 |
| `temporary_estimate_amount` | 暂估金额 | 金额 | 暂估清理、合规服务 |
| `inventory_amount` | 库存金额 | 金额 | 库存管理 |
| `accounts_payable_keywords` | 应付账款关键词 | 关键词列表 | 供应商/采购行为识别 |
| `accounts_receivable_keywords` | 应收账款关键词 | 关键词列表 | 客户类型识别 |

### 4.5 税务字段

用于合规风险、信用分层、升规预警。

| 字段ID | 字段中文名 | 类型 | 主要用途 |
|---|---|---|---|
| `taxpayer_type` | 纳税人类型 | 枚举 | 小规模/一般纳税人 |
| `tax_credit_rating` | 纳税信用等级 | 枚举 | 合规风险、信用判断 |
| `tax_amount_12m` | 近12个月纳税额 | 金额 | 经营质量、融资判断 |
| `zero_declaration_months` | 零申报月份数 | 数值 | 合规风险 |
| `tax_burden_rate` | 税负率 | 百分比 | 异常识别 |
| `small_scale_quarter_invoice_amount` | 小规模当季开票金额 | 金额 | 30万预警 |
| `small_scale_12m_invoice_amount` | 小规模近12个月开票金额 | 金额 | 500万升规预警 |

### 4.6 服务字段

用于可涨价客户、低价高耗客户、服务复杂度判断。

| 字段ID | 字段中文名 | 类型 | 主要用途 |

## 6. 字段字典与规则引擎的关系

字段字典是规则引擎的底层配置。规则引擎不能直接写死字段，而应从字段字典读取以下信息：

```text
字段ID：annual_revenue
数据类型：金额
支持操作符：大于、小于、区间
可筛选：是
可评分：是
```

这样前端才能自动知道字段应该怎么配置。

不同类型字段对应不同配置方式：

| 字段类型 | 前端配置方式 |
|---|---|
| 金额/数值 | 大于、小于、介于、为空、不为空 |
| 关键词列表 | 包含任一、不包含、全部包含 |
| 枚举 | 等于、不等于、属于、不属于 |
| 日期 | 早于、晚于、区间、近N天/近N月 |
| 布尔 | 是/否 |

## 7. 字段字典与标签体系的关系

标签不能凭空创建，应从字段字典派生。

| 标签 | 依赖字段 | 规则 |
|---|---|---|
| 高营收客户 | `annual_revenue` | 年营业收入 >= 1000万 |
| 广告投放客户 | `has_marketing_invoice_keyword` | 等于 是 |
| 高票量客户 | `monthly_avg_invoice_count` | 月均发票量 >= 指定阈值 |
| 可涨价客户 | `service_days` + `current_service_price` + `voucher_count_current_year` | 服务久 + 价格低 + 工作量高 |
| 高新潜客 | `industry` + `business_scope` + `rd_expense_current_year` | 行业/经营范围/研发费用命中 |

因此，字段字典应与标签规则表一起设计。

## 8. 建议配套配置表

字段字典不要单独存在。建议至少配套 5 张表。

| 表 | 作用 |
|---|---|
| 字段字典 | 有哪些字段、从哪来、怎么算、能怎么用 |
| 标签规则 | 哪些字段能生成哪些标签 |
| 模板规则 | 每个商机模板怎么筛客户 |
| 关键词词库 | 广告营销、高新、工商、合规、融资等场景关键词 |
| 权限与脱敏规则 | 不同角色能看到什么字段、是否脱敏 |

### 8.1 标签规则表示例

## 10. 设计原则

### 10.1 字段必须有业务口径

不能只写“收入”，要写清楚：

- 是年收入还是近12个月收入；
- 是开票收入还是报表收入；
- 是含税还是不含税；
- 是自然年还是滚动12个月；
- 更新时间是什么。

### 10.2 字段必须能解释

字段用于商机推荐时，必须能说明为什么这个字段能证明客户有需求。

示例：

> 发票项目命中广告投放关键词，说明客户已有广告投放支出，存在营销预算和外部服务采购习惯。

### 10.3 字段必须支持权限控制

营收、发票、税号、社保人数、纳税信用等级都属于敏感数据。老板、运营、顾问、销售看到的数据范围不应完全一样。

### 10.4 区分原始字段和衍生字段

原始字段示例：

```text
发票项目名称
发票金额
发票日期
```

衍生字段示例：

```text
是否命中营销关键词
近12个月营销类发票金额
最近一次营销发票日期
```

规则引擎更适合优先使用衍生字段，减少每次筛选时重复计算。

### 10.5 字段必须有状态

每个字段要标记状态：

```text
待确认
可用
口径有争议
暂不可用
废弃
```

这样MVP不会被不稳定字段拖死。

## 11. 推荐落地方式

第一版建议用 Excel / 飞书表格维护字段字典，不急于直接建设复杂配置后台。

推荐表结构：

```text
Sheet1：字段字典
Sheet2：标签规则
Sheet3：模板规则
Sheet4：关键词词库
Sheet5：权限与脱敏规则
```

先用表格把字段口径、标签规则、模板规则跑顺，再让研发按表格配置化实现。

最终目标是：

> 运营可以通过字段字典和模板规则配置出一个商机模板，而不是每次都找研发写死逻辑。
