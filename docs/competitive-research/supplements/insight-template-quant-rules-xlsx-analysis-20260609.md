## 3. 关键规则模板拆解

### 3.1 客户营收分层

客户按当年营业收入分为：

- 1000万以上：超大营收客户池，重点维护，优先匹配合规、涨价、专项服务商机；
- 300万-1000万：中高营收客户池，重点培育，关注增长、合规和增值转化；
- 50万-300万：中小营收客户池，标准服务，识别成长性客户；
- 50万以内：低营收客户池，基础维护，控制服务成本。

基础条件均包含“代账服务状态不包含已流失”。

**产品启发：** 营收分层是所有商机模板的基础底座，后续高新、合规、涨价、贷款等规则都可以叠加营收规模作为优先级判断。

### 3.2 行业专项洞察

行业专项覆盖：

- 批发和零售业；
- 制造业；
- 租赁和商务服务业；
- 建筑业；
- 科学研究和技术服务业；
- 信息传输、软件和信息技术服务业；
- 其他行业。

对应运营动作包括库存、资产、成本核算、研发费用、高新、知识产权、工程项目、税负和合规专项服务。

**产品启发：** 行业不是单纯展示字段，而应作为“行业化产品推荐”的入口。不同增值产品需要配置主目标行业和次目标行业。

### 3.3 数智产品交付洞察

表中设计了数智会计和数智开票员两类目标客户盘点：

- 数智会计匹配度高；
- 数智开票员匹配全自动或半自动；
- 按一般纳税人、小规模纳税人进一步拆分。

**产品启发：** AI顾问除了外部增值业务，也可以服务内部产品交付。例如识别哪些客户适合上线数智会计、自动开票等产品，形成“交付型商机”。

### 3.4 可涨价代账客户

该规则非常关键，已经具备较完整的组合条件：

基础条件包括：

- 代账服务状态不包含已流失；
- 代账服务时长大于等于365天；
- 近12个月累计收入大于等于100万；
- 当月代账单价与初期对比为下降或稳定；
- 当月代账单价低于机构平均单价。

增强条件包括：

- 当年凭证数大于等于60，或当年销项发票数量大于等于60；
- 当年流水条数大于等于1，或微企服咨询对话数量大于等于30，或辅助核算/专业版库存/专业版资产任一已使用。

输出名单为“涨价沟通名单”，运营动作为客户经理沟通涨价，依据是价格低、服务久、收入高、工作量和复杂度上升。

**产品启发：** 这是一个非常适合作为MVP样板的规则。它不仅筛客户，还直接对应收入提升动作，且规则可解释性强。

### 3.5 财税合规风险洞察

规则包括：

- 一般纳税人合规客户；
- 毛利率低但营收增长快；
- 成立年限长且处于亏损；
- 有水电房租但零申报；
- 有暂估。

这些规则都直接指向合规体检、风险排查、暂估清理、补票、账务规范等服务。

**产品启发：** 合规风险类商机不应只依赖金四规则，还可以从经营指标、费用痕迹、利润异常、申报状态中识别。

### 3.6 基础合规分层与合规管家分层

基础合规分层使用“基础合规洞察指数”进行 A-G 分层；合规管家分层使用“合规管家洞察指数”和近12个月累计收入进行 A-E 分层。

典型规则：

- 基础合规 A 类：指数大于等于100；
- 基础合规 B 类：指数81-99；
- 基础合规 G 类：指数小于等于8或为空；
- 合规管家 A 类：指数大于等于60且近12个月累计收入大于等于100万；
- 合规管家 B 类：指数15-59，或指数大于等于60但收入不足/缺失。

**产品启发：** 客户已经接受“指数分层”表达。我们可以在AI顾问中设计统一的“客户机会指数/产品匹配指数”，并支持按指数分层输出名单。

### 3.7 开票风险洞察

面向小规模纳税人：

- 当季开票金额20万-30万，接近30万上限；
- 近12个月开票金额400万-500万，接近500万上限。

输出名单包括“小规模当季开票预警名单”和“小规模升规风险预警名单”。

**产品启发：** 这类规则具备强时效性，适合做周期性扫描和主动提醒。

### 3.8 高新申报洞察

高新潜力客户规则包括：

- 代账服务状态不包含已流失；
- 成立日期在指定范围；
- 当年利润总额大于等于1；
- 当年研发费用大于等于1；
- 行业命中信息软件、科研技术、制造、环保、仪器、电子设备等高新相关行业。

运营动作是推荐高新认定、研发费用归集、知识产权和项目申报服务。

**产品启发：** 高新申报可以沉淀为高价值、高客单价的产品机会模板。

### 3.9 金融需求洞察

贷款潜力客户规则包括：

- 代账服务状态不包含已流失；
- 成立日期满足要求；
- 资产负债率小于等于50%；
- 股东数量小于等于4；
- 排除高风险行业；
- 存在资金压力或借款迹象；
- 同时具备一定还款能力，如销项发票金额、纳税额或固定资产。

**产品启发：** 该规则体现“需求 + 风险控制 + 还款能力”的组合思路，比单纯识别缺钱客户更成熟。

## 5. 画像字段清单分析

画像字段清单共 57 个字段，分为两大一级模块：

| 一级模块 | 字段数量 | 说明 |
|---|---:|---|
| 业务信息 | 29 | 经营情况、关键决策人、价值贡献等 |
| 服务档案 | 28 | 基础信息、财务处理、税务处理、票据处理等 |

字段类型包括：

| 字段类型 | 数量 | 说明 |
|---|---:|---|
| 文本 | 33 | 适合补充说明、备注、非结构化信息 |
| 单级选项值 | 20 | 适合做筛选、标签、统计和规则配置 |
| 整数 | 2 | 参保人数、代账年费等 |
| 时间 | 2 | 合作起始时间、代账服务起始时间等 |

### 5.1 业务信息字段

业务信息下包括：

- 经营情况：人员规模、参保人数、固定资产情况、注册地址是否挂靠、实际办公地址、办公场地面积、主营产品、产业链角色、销售对象、营销方式、发展阶段、近期目标、是否有税务稽查史；
- 关键决策人：姓名、职位、年龄、特征、合规意识、沟通频次、沟通时间、回复率、备注；
- 价值贡献：营销优先级、合作起始时间、代账服务起始时间、续费习惯、代账年费、是否复购、是否提供过转介绍。

这些字段明显服务于客户经营，而不仅是财税申报。

### 5.2 服务档案字段

服务档案下包括：

- 基础信息：主要接口人、公章存放、证照存放、资料移交、账号密码、特殊要求、异常事项、备忘事项；
- 财务处理信息：仓库核对、银行往来核对、特殊账务处理、财务备忘；
- 税务处理信息：差额征收、社保申报、个税申报、特殊税务处理、税务所属分局、专管员及电话；
- 票据处理信息：发票核定票种、税控盘、开票盘存放、是否代开票、清卡方式、票据交接、开票要求、票据备忘。

这些字段适合用于服务复杂度、服务风险、客户配合度和续费/涨价依据判断。

## 6. 对我方AI顾问的产品判断更新

结合该表，AI顾问的产品边界应进一步明确为：

> 不是简单做客户标签，也不是只做产品推荐，而是建设一套“洞察模板运营规则引擎”。

该引擎至少应包含：

1. **字段池**：企业基础、财税、票据、服务档案、客户画像、互动行为等字段；
2. **规则模板库**：营收分层、行业专项、数智产品、涨价、合规、开票、高新、金融等模板；
3. **命中逻辑**：全部满足、满足任一、全部满足 + 任一组；
4. **指数/评分机制**：基础合规指数、合规管家指数、产品匹配指数；
5. **输出名单**：每个规则必须明确产出什么名单；
6. **运营动作**：每个名单必须对应可执行动作；
7. **优先级**：高、中高、中、低等，用于顾问/销售排序；
8. **AI辅助**：将自然语言需求转换成规则、解释命中原因、生成触达话术。

## 7. 对MVP范围的影响

此前MVP建议为“客户洞察 + 产品机会评分 + AI推荐解释 + 商机导出/跟进”。该表使MVP可以再收敛为：

### 7.1 MVP必须包含的能力

| 能力 | 优先级 | 说明 |
|---|---|---|
| 洞察模板库 | P0 | 至少内置若干高价值模板，不从空白筛选器开始 |
| 规则条件组 | P0 | 支持全部满足、满足任一、全部满足+任一组 |
| 输出名单 | P0 | 每条规则必须产出可跟进客户池 |
| 运营动作说明 | P0 | 告诉顾问/销售拿到名单后做什么 |
| 优先级排序 | P0 | 高优先级名单优先跟进 |
| 字段字典 | P0 | 明确可配置字段、类型、来源和口径 |
| 模板复用和修改 | P1 | 支持运营根据客户需求调整规则 |
| 指数/评分分层 | P1 | 用于合规、产品机会和客户价值排序 |
| AI规则生成 | P1 | 用户描述需求后生成可编辑规则 |
| AI话术生成 | P2 | 根据名单和命中原因生成跟进话术 |

### 7.2 第一批建议内置模板

结合客户需求和该表，第一批模板建议优先做：

1. **可涨价代账客户**：直接对应收入提升，且规则已非常成熟；
2. **广告/数字营销商机客户**：来自前一批补充资料，字段和关键词明确；
3. **高新申报潜力客户**：高客单价，目标行业和财务条件明确；
4. **小规模开票风险预警**：规则简单、时效强，易验证；
5. **合规体检目标客户**：可复用现有合规/风险能力；
6. **贷款/融资潜力客户**：适合后续金融合作场景。

## 8. 阶段性结论

该表是目前最有价值的需求资料之一。它证明客户已经把“客户洞察”拆成了明确的运营规则：每条规则都有筛选口径、输出名单、运营动作和优先级。

因此，我方AI顾问如果要比竞品更贴近客户需求，第一阶段应优先建设：

> 洞察模板运营规则引擎 + 产品机会评分/分层 + 可解释名单输出。

其中，最适合作为短期样板的不是复杂的通用AI问答，而是：

- 可涨价客户名单；
- 广告/数字营销商机名单；
- 高新申报潜客名单；
- 开票风险预警名单；
- 合规服务目标名单。

这些模板都具备明确数据字段、明确运营动作和明确商业价值，适合快速做试点验证。
