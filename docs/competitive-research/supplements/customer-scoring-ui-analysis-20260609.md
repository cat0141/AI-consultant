# 客户自研商机评分与推荐功能补充分析

> 更新时间：2026-06-09  
> 资料来源：用户补充截图。  
> 资料背景：客户基于亿企赢导出的客户标签数据，自行让开发设计的一套分析结果展示与规则配置功能。该资料更接近客户实际想要的“结果展示层”和“规则配置层”。

## 1. 资料定位

这批截图不是亿企赢官方原生页面，而是客户根据亿企赢导出的客户标签数据，结合自身增值业务销售场景，让开发团队设计的功能原型或内部工具。

它的重要性在于：

1. 能看到客户拿到标签数据后真正想怎么用；
2. 能看到客户希望系统如何展示“推荐产品、评分、匹配依据、销售建议、参考价格”；
3. 能看到客户并不满足于简单导出数据，而是希望把数据转化为可执行的商机推荐结果；
4. 能看到客户已经将业务经验沉淀为“评分模型 + 规则权重 + 阈值 + 关键词”的形式。

## 2. 截图内容拆解

### 2.1 商机推荐卡片：高新认证-新

截图中展示了一个典型推荐结果卡片：

- 推荐产品：高新认证-新；
- 标签：资质认定、高价；
- 综合得分：87分；
- 六维度评分：行业匹配、注册年限、地区匹配、企业规模、经营范围、往来科目；
- 匹配依据：行业匹配、注册年限大于3年、经营范围包含技术开发/技术服务、应付账款存在科技服务等；
- 建议售卖方式：强烈建议立即跟进，客户已有同类采购习惯，可直接对比价格和服务质量切入；
- 推荐产品及匹配度：高新认证-新，匹配度87分；
- 参考价格：12000元。

这说明客户希望看到的不是单纯客户列表，而是“可解释的商机推荐卡片”。该卡片同时服务于管理者决策和一线顾问跟进。

### 2.2 评分明细与备选产品推荐

另一张截图展示了评分明细和备选推荐：

| 评分项 | 示例内容 | 得分 |
|---|---|---|
| 行业基础分 | 科技推广服务行业，满分40分 | +35分 |
| 经营范围加分 | 教育培训、技术服务 | +10分 |
| 权威性加分 | 信用A级、注册满3年、一般纳税人 | +15分 |
| 网络投放加分 | 未检测到网络投放记录 | +0分 |

页面还给出备选推荐产品：垫资验资-新，匹配度68分，提示可作为备选跟进。

这说明客户的真实诉求包含三层结果：

1. 主推产品；
2. 推荐得分和得分构成；
3. 备选产品和跟进建议。

因此我方MVP如果只展示“命中/不命中”，信息密度不足。更合适的结果形态是：客户名单 + 推荐产品 + 评分 + 命中原因 + 推荐动作。

### 2.3 上下游关系与网络投放识别

截图展示了“搜索特定企业的上下游关系”功能：

- 输入企业名称后可搜索；
- 支持导出CSV；
- 展示网络投放识别结果；
- 标记“存在网络投放供应商”；
- 显示匹配关键词，例如网络科技、广告有限公司；
- 给出GEO意向评分加分；
- 展示下游客户，即应收账款方向；
- 展示上游供应商，即应付账款方向；
- 展示上下游数量统计。

该能力表明，客户不仅关注企业自身标签，也关注企业的上下游交易关系。尤其是应付账款供应商中出现广告、网络科技、推广服务等关键词时，可以反推该企业可能存在网络投放或数字营销需求。

这对我方产品有两点启发：

1. 发票项目关键词只是识别广告投放商机的一种方式；应付账款/供应商名称关键词同样重要。
2. 商机识别不应只基于单企业静态字段，还应基于企业交易网络、上下游关系和往来科目。

### 2.4 星级代账客户分级量化评估表

Excel截图显示客户已有一套量化评估表，字段包括：

- 业务复杂度：资金流复杂性、存货管理；
- 合规风险度：纳税信用等级、历史税务违规、公私户混用情况、关联交易、社保/个税合规；
- 行业特性：行业类型、特殊资质/牌照；
- 行业分类示例：餐饮/零售/电商、建筑/工程、普通商贸/服务业、生产制造等。

这说明客户已经将代账客户分级从“感性判断”推进到“多维量化评估”。我方产品如果做客户分层，不能只做商机模板，也应该保留“客户星级/复杂度/风险度/行业特性”的基础评分能力。

### 2.5 规则编辑：公司法人变更-新

截图展示了“编辑匹配规则：公司法人变更-新”的配置能力。

可见配置项包括：

- 推荐阈值：当前60分，分数大于等于60才推荐给客户；
- 阈值可调：30宽松、60默认、90严格；
- 六维度权重：行业匹配25%、注册年限20%、地区匹配10%、企业规模15%、经营范围20%、往来科目10%，总计100%；
- 经营范围规则：需求关键词包括股权、法人、变更、注销；
- 排除关键词：工商代理、企业服务公司，命中则不推荐；
- 经营范围命中得分：70分，未命中得40分；
- 往来科目规则：应付账款关键词包括工商、变更、注销代理；应收账款关键词示例包括技术服务、软件开发；
- 行业规则：支持主要目标行业和次要目标行业配置。

这说明客户需要的不只是固定模板，还需要可编辑的评分规则。规则编辑能力至少包括：阈值、权重、关键词、排除词、字段规则、行业范围、重新计算推荐结果。

这进一步验证，客户实际构建的是“产品机会评分模型”。每一个增值产品都可以对应一套评分规则。

## 3. 从客户自研功能反推的产品模型

基于这批截图，客户自研工具的底层模型可以概括为：

```text
客户数据/标签
  -> 多维评分规则
  -> 推荐阈值判断
  -> 推荐产品排序
  -> 匹配依据解释
  -> 售卖建议
  -> 参考价格
  -> 导出/跟进
```

核心对象至少包括：

| 对象 | 说明 |
|---|---|
| 企业客户 | 被分析对象，包含基础信息、工商、财税、票据、交易、服务等数据 |
| 推荐产品 | 如高新认证、垫资验资、公司法人变更等增值服务 |
| 评分维度 | 行业、注册年限、地区、企业规模、经营范围、往来科目等 |
| 权重 | 不同评分维度在总分中的占比 |
| 阈值 | 分数达到多少才推荐 |
| 关键词 | 用于经营范围、往来科目、发票项目、供应商/客户名称的命中判断 |
| 排除词 | 命中后不推荐，避免误推给同行、代理机构或非目标客户 |
| 匹配依据 | 给顾问解释为什么推荐该产品 |
| 售卖建议 | 给顾问提供切入方式 |
| 参考价格 | 辅助销售报价和商机价值判断 |

## 4. 对我方AI顾问MVP的新增判断

### 4.1 结果展示层必须产品化

此前我们判断MVP应先做“客户洞察平台 + 商机筛选模板 + AI辅助规则生成”。这批截图进一步说明，光有筛选器和导出还不够，必须有面向顾问/销售可直接使用的结果展示层。

建议MVP结果页至少包含：

- 推荐产品；
- 综合得分；
- 价格标签或参考价格；
- 推荐等级，例如强烈建议跟进、可作备选、暂不推荐；
- 维度得分；
- 命中依据；
- 排除/风险提示；
- 推荐售卖方式；
- 导出或分派入口。

### 4.2 规则配置能力应提前进入P0/P1

客户已经自己做了规则编辑界面，说明规则配置不是高级能力，而是客户愿意投入开发的核心能力。

建议我方规划中将以下能力前置：

| 能力 | 建议优先级 | 原因 |
|---|---|---|
| 推荐阈值配置 | P0 | 决定是否推荐，直接影响名单质量 |
| 六维度权重配置 | P1 | 不同产品适用不同评分逻辑 |
| 关键词/排除词配置 | P0 | 是商机规则最基础的可配置项 |
| 规则重新运行 | P0 | 修改规则后必须能批量重新计算 |
| 推荐结果解释 | P0 | 顾问需要知道为什么推荐 |
| 参考价格配置 | P1 | 有助于商机价值判断和销售管理 |
| 备选产品推荐 | P1 | 同一客户可能适合多个产品，需排序展示 |

### 4.3 “产品机会评分模型”应成为核心能力

我方AI顾问不应只围绕“客户标签”建模，而应围绕“产品机会”建模。

更准确的产品能力应定义为：

> 基于客户标签和业务数据，为每个客户计算不同增值产品的匹配度，并输出可解释、可跟进、可导出的产品推荐结果。

这比“客户标签平台”更进一步，因为客户最终不是只想知道企业有哪些标签，而是想知道该向这个企业卖什么、为什么现在卖、预计价值是多少。

## 5. 对数据字段和规则体系的补充要求

### 5.1 新增字段/标签需求

| 字段/标签 | 来源 | 用途 |
|---|---|---|
| 推荐产品名称 | 产品配置 | 结果展示和销售跟进 |
| 产品价格等级 | 产品配置 | 高价/中价/低价标签，辅助优先级排序 |
| 参考价格 | 产品配置 | 商机金额估算 |
| 综合得分 | 评分计算 | 排序和推荐阈值判断 |
| 各维度得分 | 评分计算 | 可解释展示 |
| 匹配依据 | 规则命中 | 解释推荐原因 |
| 建议售卖方式 | 模板/AI生成 | 辅助顾问跟进 |
| 备选推荐产品 | 多产品评分 | 避免单一推荐，提高转化机会 |
| 上游供应商关键词 | 应付账款/发票/往来科目 | 识别服务采购习惯和外部供应商 |
| 下游客户关键词 | 应收账款/发票/往来科目 | 判断企业客户类型和收入来源 |
| 推荐阈值 | 规则配置 | 控制推荐名单松紧 |
| 排除关键词 | 规则配置 | 降低误推荐 |

### 5.2 新增规则维度

客户自研功能中出现的评分维度可作为第一版通用维度：

1. 行业匹配；
2. 注册年限；
3. 地区匹配；
4. 企业规模；
5. 经营范围；
6. 往来科目；
7. 权威性加分，例如信用等级、一般纳税人、注册年限；
8. 网络投放加分；
9. 上下游关系加分；
10. 合规风险或业务复杂度加分。

## 6. 与上一阶段MVP建议的关系

上一阶段建议MVP采用“两层能力 + 一个样板模板”：

1. 基础能力层：企业维度字段池、发票项目关键词检索、筛选器、结果列表、导出；
2. AI辅助层：自然语言生成规则、命中原因解释、字段/关键词推荐；
3. 样板模板：广告/数字营销服务商机筛选模板。

本批截图将MVP进一步升级为：

```text
基础数据层
  -> 规则/评分配置层
  -> 产品机会评分层
  -> 推荐结果展示层
  -> 导出/分派/跟进层
```

因此，样板模板不应只输出“广告/数字营销企业名单”，而应输出类似：

- 推荐产品：网络推广服务 / GEO优化 / 新媒体推广；
- 综合得分：例如82分；
- 命中依据：发票项目包含广告投放，供应商名称包含网络科技，近12个月推广相关发票金额达到阈值；
- 建议售卖方式：客户已有同类采购习惯，可从效果优化、成本控制、服务质量对比切入；
- 参考价格或价格等级；
- 备选产品。

## 7. 阶段性判断更新

结合内部访谈、客户洞察截图、企业/发票维度资料以及本批客户自研功能截图，当前判断更新为：

> 我方AI顾问第一阶段的核心不只是“筛客户”，而是“基于客户标签和业务数据，为增值产品计算客户匹配度，并输出可解释的推荐结果”。

产品形态建议从“客户洞察平台”进一步明确为：

> 客户洞察 + 产品机会评分 + AI推荐解释 + 商机导出/跟进。

这比竞品宣传中的“AI合规顾问”更贴近当前试点客户的真实动作，也更容易形成可收费能力。
