## 1. 调研背景

近期竞品亿企赢对外宣传“AI合规顾问”，围绕代账机构在日常服务、客户经营、商机挖掘和风险预警中的痛点，提出“提效、固客、增收、避险”的产品价值主张。与此同时，我方内部也在讨论建设自研AI顾问能力，需要判断：竞品真正构成威胁的能力是什么，我方第一阶段应该优先做什么，以及哪些资料仍需补充验证。

本次补充的内部沟通记录显示，真实客户需求并不只是“AI问答”或“财税政策咨询”，而是更聚焦于从大规模存量客户中进行数据筛选、客户分层、标签管理和商机挖掘。

## 2. 竞品初步分析结论

### 2.1 竞品产品定位

亿企赢AI合规顾问可初步判断为面向代账机构的AI化服务升级方案。它并非单一问答工具，而是试图把代账机构日常服务、客户触达、风险预警、增值服务转化和合规责任管理串成闭环。

从竞品视频和公开资料看，其产品叙事重点包括：

- 面向代账机构老板和顾问；
- 依托票、财、税、工商及政策法规等数据；
- 通过AI、大模型和流程化引擎提供服务自动化与风险识别；
- 通过企业服务群、小程序、任务提醒等方式提升企业客户感知；
- 通过风险提示和商机推荐帮助代账机构做增值服务转化。

### 2.2 竞品核心卖点

竞品当前对外主张可以归纳为四个关键词：

| 卖点 | 含义 | 对代账机构的价值 |
|---|---|---|
| 提效 | 日常服务自动化 | 降低重复沟通、资料催收、税金测算、进度提醒等工作量 |
| 固客 | 服务过程可视化 | 让客户看见服务过程，提高客户感知和续费粘性 |
| 增收 | 挖掘增值业务机会 | 基于客户数据和风险点识别潜在商机 |
| 避险 | 风险监控与预警 | 降低因客户不配合、资料缺失、申报风险导致的责任争议 |

### 2.3 竞品对我方的核心威胁

竞品威胁不在于单点AI能力，而在于其可能将代账机构的“存量客户经营能力”产品化。具体体现为：

1. **数据入口强**：亿企赢在财税SaaS、代账系统、企业端小程序等方面已有生态基础。
2. **价值叙事清晰**：提效、固客、增收、避险直接对应代账机构老板关心的问题。
3. **工作流绑定强**：竞品可能把风险识别、服务提醒、客户触达、顾问跟进绑定到日常工作流程中。
4. **增值服务导向明显**：不是只做合规提醒，而是服务于代账机构从存量客户中找业务机会。

## 3. 内部客户需求访谈摘要

### 3.1 客户背景

内部沟通记录中提到的客户约有2万多户企业客户，属于较大规模代账机构。客户当前已经在持续向我方索取多维度数据，用于自行分析客户分层和潜在商机。

该客户当前业务特征：

- 存量企业客户规模大；
- 已有主动做客户分层和商机挖掘的意识；
- 具备后续转化能力，不完全依赖系统给出谈单方案；
- 经常需要导出客户信息、票据数据、财税数据等基础统计数据；
- 会自行使用AI或手工方式对导出的数据进行二次加工。

### 3.2 当前痛点

客户的核心痛点不是“不知道怎么谈单”，而是“客户太多，看不过来，无法快速找到值得跟进的客户”。

主要痛点包括：

- 企业客户数量大，人工逐户识别商机效率低；
- 当前数据获取依赖人工工单，响应慢、复用差；
- 数据分散在客户信息、票据、科目、工商、资质等不同维度；
- 现有规则多聚焦金四风险，无法覆盖更多增值业务机会；
- 客户希望根据自身业务经验灵活配置筛选规则，而不是只使用固定报告。

### 3.3 客户真正要的能力

根据沟通记录，客户当前明确需要的是：

> 一个支持多维数据筛选、标签组合、客户分层、商机识别和数据导出的能力平台。

更具体地说，客户希望系统能够：

- 从存量客户中筛选符合特定条件的企业；
- 自动给企业打标签；
- 支持不同标签和字段自由组合；
- 支持用户按照自己的规则调整筛选条件；
- 输出客户名单或分析结果；
- 支持导出，方便顾问后续分批营销；
- 不强依赖系统给出复杂谈单流程，客户自身有业务转化能力。

## 5. 对我方AI顾问产品定位的影响

### 5.1 AI顾问不应只做财税问答

如果我方将AI顾问仅定位为“政策问答”或“财税咨询助手”，会偏离当前客户最迫切的需求。真实客户更看重的是系统能否帮助他们从大量存量客户中发现商机，并把数据导出来用于经营动作。

因此，我方AI顾问应优先定位为：

> 面向代账机构的客户经营与商机挖掘型AI顾问。

后续再逐步扩展为合规问答、风险解释、跟进话术、任务编排等能力。

### 5.2 第一阶段重点应是“数据型AI顾问”

第一阶段建议聚焦数据能力，而不是复杂AI交互。

核心目标：

> 把目前依赖大数据工单、人工导数、人工加工的客户筛选工作，产品化为可自助使用的筛选与标签平台。

第一阶段需要解决的是：

- 数据能不能取到；
- 字段是否准确；
- 筛选是否灵活；
- 标签是否可配置；
- 结果是否可导出；
- 规则是否能沉淀复用；
- 是否能覆盖真实商机场景。

### 5.3 第二阶段再做“经营型AI顾问”

在数据筛选能力稳定后，再叠加AI解释和经营动作能力：

- 为什么该客户被筛出来；
- 适合推荐什么产品；
- 顾问应如何触达；
- 是否自动生成客户跟进任务；
- 是否推送至服务群或顾问工作台；
- 是否跟踪商机转化结果；
- 是否反向优化筛选规则。

## 6. MVP功能建议

### 6.1 MVP目标

MVP不追求一次性做完整AI顾问，而是先验证一个最小闭环：

> 用户通过规则或自然语言提出筛选需求，系统从存量客户数据中生成客户名单，自动附带标签和命中原因，并支持导出或分派给顾问跟进。

### 6.2 MVP功能清单

| 模块 | 功能 | 优先级 |
|---|---|---|
| 客户数据池 | 汇总客户基础信息、票据、科目、申报、工商、资质等数据 | P0 |
| 筛选器 | 支持字段筛选、条件组合、区间筛选、关键词匹配 | P0 |
| 标签体系 | 系统标签 + 自定义标签，支持自动打标 | P0 |
| 商机规则模板 | 内置金四风险、广告推广、工商资质、库存等模板 | P0 |
| 结果列表 | 输出客户名单、命中标签、关键字段、命中原因 | P0 |
| 数据导出 | 支持导出Excel/CSV，便于线下转化 | P0 |
| 规则保存 | 支持保存常用筛选规则，下次复用 | P1 |
| 自然语言取数 | 支持用自然语言生成筛选规则 | P1 |
| 商机说明 | 解释为什么该客户可能存在某类商机 | P1 |
| 顾问分派 | 将客户名单分派给对应顾问 | P2 |
| 触达话术 | 生成产品推荐话术和客户沟通话术 | P2 |
| 转化跟踪 | 记录跟进结果，反向评估规则效果 | P2 |

### 6.3 MVP优先规则模板

建议第一批规则模板从客户已真实提出过的数据需求中提炼，不从产品经理想象出发。当前可先设计以下模板：

1. **金四风险客户筛选**：命中已有金四风险规则的客户。
2. **广告推广商机筛选**：科目或发票中出现广告、推广、宣传、传媒、投放等相关特征的客户。
3. **高营收客户筛选**：营收较高、票据量较大、服务费较高的高价值客户。
4. **库存类客户筛选**：商贸企业、库存条数或库存金额较高的客户。
5. **工商资质机会筛选**：经营范围、工商变更、资质缺口与增值服务相关的客户。
6. **低服务感知客户筛选**：服务时长较长但互动较少、服务过程不可见的客户。

## 7. 产品设计原则

### 7.1 先准确，后智能

客户明确表示“数据准确，自己能用上，能导出来”即可产生价值。因此第一阶段不应过度追求复杂智能化，而应优先保障字段口径、筛选结果和导出数据准确。

### 7.2 先筛选，后转化

客户已有转化能力，产品不必一开始就做完整营销闭环。先把“找客户”做出来，再逐步补充“怎么谈”“怎么跟”“怎么转化”。

### 7.3 先规则化，再AI化

底层应先建设规则引擎和标签体系，再让AI承担规则生成、规则解释、字段匹配、自然语言取数等辅助能力。

### 7.4 支持客户自定义

不同代账机构的增值业务不同，固定标签和固定报告难以满足全部场景。必须支持客户基于自己的业务经验自定义规则、组合字段和保存模板。

## 10. 阶段性结论

基于当前资料，我方AI顾问第一阶段不建议以“财税问答机器人”为核心切入，而应以“客户经营数据分析与商机挖掘”为核心切入。

更具体地说，MVP应优先做成：

> 一个让代账机构可以自助筛选存量客户、生成客户标签、识别商机、导出名单的AI辅助数据分析平台。

该方向具备较强需求确定性，因为客户已经通过人工工单和外部AI工具在做类似事情。产品化后可以直接替代当前低效的数据导出和人工加工流程，并为后续AI顾问的合规解释、话术生成、顾问分派、转化追踪打基础。

### 11.2 截图二：洞察模板/规则筛选器

截图显示一个典型的规则筛选模板，具备多层条件组合能力：

- 外层支持“满足以下所有条件”；
- 内层支持“满足以下任一条件”；
- 字段支持数值区间、包含/不包含、枚举标签等操作；
- 可组合代账服务状态、服务时长、近12个月累计收入、当月代账单价变化、凭证数、销项发票数量、流水条数、微信服务咨询对话数、辅助核算使用状态、库存/资产使用状态等维度；
- 页面底部有“使用模板”按钮，说明规则可以沉淀为模板并复用。

该截图对我方产品设计的启发非常直接：

1. **筛选器是核心能力，不是辅助能力。** 客户真实需要的是可自行配置、可复用、可导出的规则引擎。
2. **字段来源必须跨域。** 竞品规则已经把服务数据、经营收入、票据数据、流水、微信咨询、软件功能使用状态等放在同一个筛选器中。
3. **规则需要支持嵌套组合。** 单层筛选不够，需要支持“所有/任一”的条件组嵌套。
4. **模板化是降低使用门槛的关键。** 不能只给空白筛选器，应内置典型商机模板。
5. **AI可以承担规则生成和解释，但底层仍是规则引擎。** AI顾问第一阶段应优先辅助用户把自然语言需求转换为可执行筛选规则。

### 11.3 对我方MVP的新增要求

基于上述截图，MVP功能清单需要补充以下内容：

### 11.4 当前判断更新

结合内部会议记录和本次截图，当前判断进一步收敛为：

> 我方AI顾问的第一阶段产品形态，应以“客户洞察平台 + 商机筛选模板 + AI辅助规则生成”为核心，而不是以“聊天式AI问答”为核心。

也就是说，产品主入口可以是客户洞察、商机速览、洞察模板、洞察报表；AI能力嵌入在筛选规则生成、字段解释、命中原因说明、商机话术生成等位置。这样更贴近客户正在选型和愿意付费的能力。

## 12. 后续图片资料处理方式

建议后续资料采用“有一张处理一张”的方式，不等全部图片收齐再分析。原因是：

1. 每张截图往往对应一个具体功能点，及时沉淀可以避免遗漏；
2. 后续图片可能来自不同竞品或不同页面，逐张分析更容易形成结构化功能清单；
3. 先记录单图观察，再在资料收齐后做统一归纳，可以同时保证细节和整体判断；
4. 若等待一次性处理，容易把截图中的字段、按钮、交互细节丢失。

建议流程：

- 每收到一批截图，先记录图片来源、页面名称、可见字段、交互能力、对我方启发；
- 每批资料更新一次GitHub文档；
- 资料阶段性完整后，再输出一版“产品方案判断稿”或“PRD草案”。

## 13. 补充资料：企业维度与发票维度筛选需求（2026-06-09）

### 13.1 新增资料摘要

本次补充资料明确给出两个可直接进入MVP字段池的维度：企业维度与发票维度。其中，企业维度用于构建客户画像和基础筛选条件，发票维度用于识别“广告/数字营销/网络推广”类商机。

- 搜索引擎推广；
- 媒体投放；

这些关键词可以直接沉淀为“广告/数字营销商机识别规则”的第一版关键词词库。

### 13.4 可形成的首个明确商机模板：广告/数字营销服务商机

基于企业维度与发票维度，可以形成一个较明确、可落地的商机筛选模板。

**模板名称：广告/数字营销服务商机筛选**

**筛选目标：** 找出已有广告投放、网络推广或数字营销支出痕迹的企业，供代账机构进一步推荐新媒体推广、营销服务、广告投放优化、财税合规检查等增值业务。

**建议筛选逻辑：**

```text
满足以下所有条件：
1. 企业为当前机构存量客户；
2. 企业状态正常，且未流失；
3. 发票项目包含以下任一关键词：
   网络投放 / 广告投放 / 数字营销 / 信息流 / 搜索引擎推广 / 媒体投放 / SEO / SEM / 营销推广 / 品牌推广；
4. 可选增强条件：年营业收入达到一定阈值，或月均发票量达到一定阈值；
5. 可选排除条件：已购买相关营销服务、近期已跟进、已明确拒绝。
```

**建议输出字段：**

| 输出字段 | 说明 |
|---|---|
| 企业名称 | 便于顾问识别客户 |
| 税号 | 便于唯一匹配和导出后回填 |
| 行业 | 判断推广需求是否合理 |
| 年营业收入 | 判断客户价值和预算能力 |
| 月均发票量 | 判断业务活跃度 |
| 发票项目命中关键词 | 解释为什么被筛出 |
| 命中发票数量 | 判断该类支出出现频率 |
| 命中发票金额 | 判断推广投入规模 |
| 最近一次命中时间 | 判断商机新鲜度 |
| 纳税信用等级 | 判断是否存在合规风险或沟通敏感度 |
| 关联公司数量 | 判断是否有转介绍或集团拓展机会 |

### 13.5 对产品方案的新增判断

本次补充资料使MVP方向更加明确：第一版不需要先覆盖所有商机类型，可以先选择“广告/数字营销商机”作为样板场景。原因是：

1. **字段条件明确。** 企业维度和发票关键词已经具备初步字段清单，不需要等待完整标签体系设计完成。
2. **业务动作清晰。** 筛出的客户可以直接给顾问或销售用于营销服务推荐。
3. **可解释性强。** 命中原因可以直接展示为“发票项目包含某关键词、命中金额/次数”。
4. **易验证价值。** 可以通过导出名单后跟进转化，快速判断规则有效性。
5. **可扩展为模板机制。** 该规则跑通后，可复制方法建设工商资质、库存管理、金四风险、高价值客户等模板。

### 13.6 对字段字典和数据产品的要求

该资料也说明，AI顾问底层必须建设“字段字典 + 关键词词库 + 规则模板”的组合能力。

| 能力 | 要求 |
|---|---|
| 字段字典 | 明确企业字段、发票字段、财税字段、服务字段的字段名、来源、口径、更新时间、权限范围 |
| 关键词词库 | 支持按商机场景维护关键词，如广告推广、资质办理、库存管理、贷款融资等 |
| 规则模板 | 支持将字段条件、关键词条件、阈值条件、排除条件组合为可复用模板 |
| 命中解释 | 输出每家企业命中哪些字段、哪些关键词、命中次数和金额 |
| 导出字段配置 | 支持用户选择导出字段，满足客户后续二次加工需要 |
| AI辅助配置 | 用户输入“帮我找有广告投放痕迹的客户”，AI自动匹配发票项目关键词和企业价值筛选字段 |

### 13.7 更新后的MVP建议

基于当前资料，MVP建议调整为“两层能力 + 一个样板模板”：

1. **基础能力层：** 企业维度字段池、发票项目关键词检索、筛选器、结果列表、导出。
2. **AI辅助层：** 自然语言生成规则、命中原因解释、字段/关键词推荐。
3. **样板模板：** 广告/数字营销服务商机筛选模板。

该样板模板应作为第一版验证场景，优先用于试点客户或内部销售验证。若该模板能产生可跟进客户名单并形成转化反馈，再继续扩展其他商机模板。
