# AI顾问产品竞品调研与自研判断

> 更新时间：2026-06-09  
> 资料来源：竞品视频截图/录屏、公开资料初步检索、2026-06-08内部沟通记录、客户洞察平台截图、补充数据维度资料、客户自研规则表。  
> 当前状态：阶段性判断文档。本版重点完成产品方向拆分：AI服务顾问效率线、客户洞察增长线。

## 1. 关键判断：需要拆成两条产品线

随着资料补充，当前可以明确判断：

> 近期收集到的资料实际覆盖了两类不同需求：一类是AI顾问带来的服务提效，另一类是客户洞察带来的营收增长。二者可共用数据和AI能力，但不应混为一个MVP。

如果继续把所有资料都归入“AI顾问”，会导致产品定位发散：既要做问答、催办、税金解释，又要做商机挖掘、客户分层、产品机会评分、增值业务推荐，最终一期范围过大，也无法清晰衡量成功。

因此，本项目后续建议拆成两条线推进：

| 产品线 | 核心目标 | 典型能力 | 核心指标 |
|---|---|---|---|
| AI服务顾问：效率提升线 | 提高顾问服务效率和服务标准化 | 高频问答、税金说明、资料催办、风险解释、服务进度沟通、留痕 | 回复耗时下降、顾问采纳率、单户服务耗时下降、催收响应率 |
| 客户洞察增长线：营收增长线 | 从存量客户中发现增值业务和涨价机会 | 客户分层、洞察模板、商机筛选、产品机会评分、输出名单、运营动作 | 商机数、转化率、增值收入、涨价金额 |

## 2. AI服务顾问：效率提升线

### 2.1 产品定位

AI服务顾问应定位为：

> 代账顾问的日常服务助手，负责自动生成客户问答、税金说明、资料催办、风险解释和服务进度沟通内容，从而提升服务效率、服务一致性和责任留痕能力。

它的主线是“提效”，不是“找商机”。

### 2.2 目标用户

| 用户 | 核心诉求 |
|---|---|
| 代账顾问/会计 | 减少重复回复、催资料、解释税金、整理客户问题的工作量 |
| 顾问主管/机构老板 | 提升人效、降低服务质量波动、减少客户投诉和责任争议 |
| 企业客户 | 更快获得问题回复、进度提醒、税金说明和风险解释 |

### 2.3 MVP建议

第一版建议验证以下闭环：

> 顾问在服务过程中遇到高频客户问题或催办事项时，AI能基于业务数据生成可发送、可解释、可留痕的话术，减少人工编辑时间。

建议MVP功能：

| 模块 | 功能 | 优先级 |
|---|---|---|
| 服务上下文聚合 | 聚合客户基础信息、当前账期、申报状态、资料缺失、税金结果 | P0 |
| 高频问答助手 | 基于标准知识和客户上下文生成回复 | P0 |
| 税金说明生成 | 自动生成当期税金测算说明和变化原因 | P0 |
| 催资料话术生成 | 根据缺失资料生成催办消息 | P0 |
| 风险解释生成 | 对风险点生成客户可理解解释 | P0 |
| 顾问编辑与确认 | AI生成内容必须经顾问确认后发送 | P0 |
| 留痕记录 | 保存生成内容、发送内容、客户确认状态 | P0 |
| 服务群发送 | 对接企微/服务群，支持复制或自动推送 | P1 |
| 模板管理 | 支持机构维护常用话术模板 | P1 |
| 问题归类统计 | 汇总客户高频问题，反向优化知识库 | P2 |

### 2.4 不建议一期纳入的内容

以下内容属于“客户洞察增长线”，不建议作为AI服务顾问一期主线：

- 客户分层；
- 商机筛选；
- 产品机会评分；
- 可涨价客户名单；
- 高新申报潜客名单；
- 广告/数字营销商机名单；
- 贷款/融资潜客；
- 增值业务推荐排序。

## 3. 客户洞察增长线：营收增长线

### 3.1 产品定位

客户洞察增长线应定位为：

> 代账机构的存量客户增长工具，负责通过洞察模板、规则引擎和产品机会评分，从已有客户中识别可涨价、可转化、可推荐增值服务的客户名单。

它的主线是“增收”，不是“服务提效”。

### 3.2 资料证据

今天补充的资料主要属于这条线，包括：

- 客户按照亿企赢导出的客户标签数据，自行开发分析结果展示功能；
- 推荐产品卡片：如高新认证、垫资验资、公司法人变更等；
- 六维度评分：行业匹配、注册年限、地区匹配、企业规模、经营范围、往来科目；
- 匹配依据、建议售卖方式、参考价格；
- 上下游关系和网络投放识别；
- 《洞察模板量化运营规则表.xlsx》中的42条量化洞察规则和57个画像字段。

这些资料证明，客户真正要的是把客户标签和财税数据转化为可运营、可跟进、可增收的名单。

### 3.3 MVP建议

第一版建议验证以下闭环：

> 基于客户数据和规则模板，自动生成可跟进客户名单，并为每个客户给出推荐产品、命中依据、优先级和运营动作。

建议MVP能力：

| 能力 | 优先级 | 说明 |
|---|---|---|
| 字段字典 | P0 | 明确企业、财税、发票、服务、画像字段来源和口径 |
| 洞察模板库 | P0 | 内置高价值模板，降低用户配置成本 |
| 规则条件组 | P0 | 支持全部满足、满足任一、全部满足+任一组 |
| 输出名单 | P0 | 每条规则必须产出可跟进客户池 |
| 命中原因 | P0 | 展示客户为什么被筛出 |
| 运营动作 | P0 | 告诉顾问/销售下一步做什么 |
| 优先级排序 | P0 | 高价值、高紧急名单优先处理 |
| 导出能力 | P0 | 支持Excel/CSV导出，满足客户二次加工和线下转化 |
| 产品机会评分 | P1 | 给不同产品计算匹配度 |
| 规则配置 | P1 | 支持阈值、权重、关键词、排除词调整 |
| AI规则生成 | P1 | 用户用自然语言描述目标客户，AI生成可编辑规则 |
| AI话术生成 | P2 | 根据推荐产品和命中原因生成跟进话术 |
| 转化跟踪 | P2 | 记录跟进和成交结果，反向评估模板质量 |

### 3.4 第一批建议模板

| 模板 | 价值 | 说明 |
|---|---|---|
| 可涨价代账客户 | 直接提升代账收入 | 根据服务时长、收入、单价、工作量、复杂度识别涨价名单 |
| 广告/数字营销商机客户 | 增值服务转化 | 根据发票项目、供应商/往来科目关键词识别营销服务需求 |
| 高新申报潜力客户 | 高客单价资质服务 | 根据行业、注册年限、研发费用、技术服务经营范围识别 |
| 小规模开票风险预警 | 合规提醒和风险服务 | 根据当季/近12个月开票金额接近阈值识别 |
| 合规体检目标客户 | 合规服务转化 | 根据毛利率、亏损、零申报、暂估、税务风险识别 |
| 贷款/融资潜力客户 | 金融服务转化 | 根据资金压力、还款能力、负债率和行业风险识别 |

## 4. 两条线的边界

| 对比项 | AI服务顾问 | 客户洞察增长线 |
|---|---|---|
| 核心目标 | 提效 | 增收 |
| 使用场景 | 日常服务、问答、催办、解释 | 客户分层、商机挖掘、产品推荐 |
| 核心对象 | 客户问题/服务事项 | 企业客户/推荐产品/商机名单 |
| 输出结果 | 回复话术、说明、提醒、留痕 | 客户名单、推荐产品、评分、运营动作 |
| 主要用户 | 顾问、会计、客服主管 | 老板、运营、销售、客户经理 |
| 关键指标 | 回复耗时、采纳率、人效提升 | 商机数、转化率、增值收入、涨价金额 |
| 一期建议 | 若公司目标是AI顾问提效，应优先 | 可作为并行项目或二期增长模块 |

## 5. 与竞品亿企赢的关系

亿企赢对外讲“提效、固客、增收、避险”，本质上也是把多个价值方向包装在一个AI合规顾问叙事里。

但我方在内部立项和MVP设计时，不建议直接照搬这个大而全包装。更适合拆成：

1. **AI服务顾问**：对应提效、服务标准化、部分避险；
2. **客户洞察增长线**：对应增收、固客、客户经营；
3. **合规风险顾问**：后续可独立承接风险监控、合规体检、责任留痕。

这样拆分后，每条线的目标、用户、场景、指标都更清晰。

## 7. 阶段性结论

当前最重要的结论是：

> AI顾问和客户洞察增长不是同一个MVP。前者解决效率提升，后者解决营收增长。二者可以共享数据、标签、规则、AI解释能力，但产品设计、优先级和考核指标必须拆开。

如果公司当前目标是“我们也要做AI顾问”，建议一期优先做AI服务顾问效率线；如果当前目标是抢客户、应对竞品、服务大客户增值诉求，则客户洞察增长线可以作为并行项目或二期重点。
