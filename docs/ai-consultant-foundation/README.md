# AI 顾问基础文件

> 目录用途：沉淀 AI 顾问产品设计所依赖的基础事实、能力盘点、验证假设和证据审查。  
> 原则：会议讨论不能直接等同于产品事实；凡涉及产品决策，必须区分“已有能力”“待确认能力”“假设”“证据”和“个人判断”。

## 文件说明

1. `YUNZHANGFANG_EXISTING_CAPABILITIES_BASELINE.md`
   - 从 2026-06-09 AI顾问商业化讨论会、2026-06-17 中小微管理团队例会中梳理云帐房已有能力。
   - 用途：作为 AI 顾问产品设计的能力底座，不直接代表所有能力已达到可商业化质量。

2. `AI_CONSULTANT_PHASE1_ASSUMPTIONS_AND_EVIDENCE.md`
   - 对 AI 顾问第一阶段方向进行假设拆解、外部证据审查和内部验证指标设计。
   - 用途：避免把会议观点当成结论，用数据决定 MVP 范围和优先级。

## 当前原则

- AI 顾问 1.0 可以先聚焦顾问/流程会计提效，但这仍然只是产品假设。
- “替代流程会计”“减少 70%-80% 工作量”等说法必须通过真实客户数据验证后才能进入销售话术。
- 第一阶段优先选择可度量、可回滚、低风险的场景：数据查询、回复建议、催办/确认、资料回收、待办生成。
- 不以单个客户、单场会议或竞品宣传作为产品方向的充分依据。
